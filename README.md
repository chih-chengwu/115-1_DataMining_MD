## 📖 課程介紹XXXXXXX

本課程介紹資料探勘（Data Mining）的基本概念、資料前處理、機器學習演算法、模型評估以及實作應用。

課程將搭配：

- Python
- Jupyter Notebook
- VS Code
- GitHub
- Kaggle

讓學生循序漸進學習資料探勘技術。

## 🎯 課程目標

完成本課程後，學生將能：

- ✔ 瞭解資料探勘流程（CRISP-DM）
- ✔ 使用 Python 進行資料分析
- ✔ 熟悉資料前處理技巧
- ✔ 建立機器學習模型
- ✔ 評估模型效能
- ✔ 完成資料探勘專題
